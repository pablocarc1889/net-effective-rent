NET EFFECTIVE RENT — iPhone Web App v1

This version reproduces the calculation structure of the uploaded Excel calculator:
- EDATE lease end date minus 1 day
- prorated first/final periods
- lease month numbering
- total concession = MIN(total gross rent, monthly rent × months free + dollar concession)
- concession spread evenly across the requested full months
- concession only applied to full calendar months
- net effective rent = total rent paid / lease term

To use as an iPhone Home Screen app:
1. Put these files on any static web host (for example GitHub Pages).
2. Open the site in Safari on your iPhone.
3. Tap Share → Add to Home Screen.
4. Launch it from the new Home Screen icon.

No App Store or Mac is required.
